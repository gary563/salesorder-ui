1. install java jdk 17 above
2. install spring tool suite latest version
3. download the copy and place into workspace folder
4. from spring boot, import maven->Existing maven project. Select the folder salesorder-ui
5. select pom.xml and next
6. to run the project, select right click and run as maven clean, maven install.
7. Execute Spring Boot App, launch localhost:8080 on browser
